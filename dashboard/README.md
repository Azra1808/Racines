# Tableau de bord facilitateur RACINES

Ce prototype statique est le livrable E4 du tableau de bord : il met en scène le suivi de l'accès, de l'apprentissage et des signaux de protection sans afficher de donnée personnelle.

## Lancer localement

Ouvrir `index.html` dans un navigateur. Aucun serveur, compte ni donnée distante n'est nécessaire.

## Ce qui est volontairement synthétique

Tous les compteurs, canaux et signaux affichés sont fictifs. Ils servent à démontrer l'interface et ne doivent jamais être utilisés dans le dossier comme résultat terrain.

## Passage en production

Avant connexion à une source de données réelle :

1. définir les indicateurs et la conservation des données avec le programme ;
2. ne stocker aucun nom, téléphone ou détail sensible dans ce tableau ;
3. soumettre les signaux à un protocole humain documenté ;
4. tracer la provenance et la date de chaque agrégat ;
5. contrôler le lien public depuis une navigation privée.
